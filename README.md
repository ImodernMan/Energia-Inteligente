# Energia-Inteligente

## ODS 7 — Energia Limpa e Acessível

### Sobre o projeto

Nosso projeto tem como objetivo desenvolver um aplicativo mobile híbrido voltado para eficiência energética residencial, contribuindo para o ODS 7 — Energia Limpa e Acessível.

### Problema

Muitas pessoas não possuem informações suficientes sobre seu próprio consumo de energia e têm dificuldade para identificar possíveis desperdícios e maneiras de melhorar a eficiência energética.

### Público-alvo

Usuários residenciais que desejam acompanhar seu consumo de energia, identificar possíveis desperdícios e receber recomendações para economizar energia.

### Solução proposta

O sistema será um aplicativo mobile híbrido que permitirá ao usuário registrar e acompanhar informações relacionadas ao seu consumo de energia.

O back-end será responsável pelo processamento das informações, regras do sistema e comunicação com o banco de dados.

### Utilização da Inteligência Artificial

A Inteligência Artificial será utilizada no segmento de eficiência energética residencial.

A IA analisará os dados de consumo fornecidos pelo usuário, buscando identificar padrões ou possíveis desperdícios e gerar recomendações personalizadas para melhorar a eficiência energética.

### Funcionalidades do MVP

1. Registro de informações de consumo de energia.
2. Acompanhamento e análise do consumo.
3. Geração de recomendações utilizando IA.
